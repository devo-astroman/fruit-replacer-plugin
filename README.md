# fruit-selector-plugin
This is a basic project of a Roblox plugin that displays a basic dropdown to select a fruit and shows the selected fruit, it is created with Visual Studio Code, Rojo, OnyxUI and Fusion

## Getting Started
In order to run the project you need to download and place the Fusion 3.0 library:

    1-Download .zip project at asset from https://github.com/dphfox/Fusion/releases (here explains how https://elttob.uk/Fusion/0.3/tutorials/get-started/installing-fusion/)
    2-Extract the .zip file and find the folder "src"
    3-Rename src to Fusion
    4-Copy the renamed folder from 'src' to 'Fusion' to your project at src/plugin-scripts/packages

Syncing with Roblox Studio
    1-Run rojo serve from your root project
    2-Open Roblox Studio and run rojo plugin to connect
